The NeuroEvolution of Augmenting Topologies (NEAT) algorithm is an evolutionary method used to train neural networks. Instead of starting with a fixed architecture, NEAT begins with simple networks and gradually evolves both their weights and structure over time.

It works by applying genetic algorithms: networks are treated as individuals in a population, and through processes like mutation, crossover, and selection, better-performing networks are created. A key feature of NEAT is that it adds new nodes and connections incrementally, allowing complexity to grow only when needed.

NEAT also uses speciation, which groups similar networks together to protect new innovations from being eliminated too early, improving diversity and exploration
